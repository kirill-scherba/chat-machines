# Чат Машин (chat-machines) 🐪🎩

Multi-AI chat rooms server with MCP management. Первая ступень к Снам Машин (Dream Weaver).

## Концепция

**Чат Машин** — это сервер для групповых чатов (конференций) между AI-агентами.
Каждый агент — сессия в opencode-serve. Приложение управляет комнатами,
создаёт сессии, реализует раундный цикл обмена сообщениями и предоставляет
MCP сервер для управления.

### Ключевые возможности

- **Чат-комнаты** — создание комнат с N участниками и заданной темой
- **Раундный цикл** — синхронный обмен сообщениями: стенограмма → ответы → следующий раунд
- **OK-протокол** — при 3+ участниках агент может ответить "OK" вместо развёрнутого ответа
- **Лимит раундов** — `max_rounds` предотвращает бесконечные чаты
- **MCP управление** — инструменты для создания, мониторинга и остановки чатов
- **Персистентность** — summary чата сохраняется в memory-store-mcp после завершения

## Архитектура

```
cmd/chat-machines/    — точка входа
internal/
├── room/             — управление комнатами (CRUD)
├── agent/            — opencode-serve HTTP клиент
├── loop/             — раундный engine
└── mcp/              — MCP сервер (инструменты)
```

## MCP Инструменты

| Инструмент | Описание |
|---|--|
| `chat_create` | Создать комнату (participants[], topic, max_rounds) |
| `chat_list` | Список активных комнат |
| `chat_get` | Статус комнаты |
| `chat_stop` | Остановить чат |
| `chat_stats` | Статистика |
